# 실시간 코딩 회의방 (데모)

방을 만들고 같은 링크로 접속한 사람들이 Monaco 편집기에서 코드를 동시에 편집하는 데모입니다.
Vite + React + TypeScript, Monaco, Yjs, Hocuspocus(SQLite 저장)를 사용합니다.

## 실행 방법

터미널 두 개에서 각각 실행합니다. (한 번에 실행하는 스크립트는 `ROADMAP.md` 6단계에서 추가 예정)

```bash
# 터미널 1: 동기화 서버 (ws://localhost:1234)
cd server
npm install
npm run dev

# 터미널 2: 클라이언트 (http://localhost:5173)
cd client
npm install
npm run dev
```

## 동작 확인

1. 브라우저에서 `http://localhost:5173`을 열고 "방 만들기"를 누릅니다.
2. 주소(`/room/xxxxxxxx`)를 다른 브라우저 창에 붙여 넣으면 같은 방에 들어가 동시에 편집할 수 있습니다.

## 라이브 콘솔 (코드 실행)

편집기 아래 콘솔 패널에서 코드를 실행하고, 결과를 같은 방의 모든 참여자가 실시간으로 봅니다.
코드는 **실행 버튼을 누른 사람의 브라우저**에서 실행되며, 서버는 코드를 실행하지 않습니다.

### 사용법

1. 상단에서 언어를 JavaScript 또는 Python으로 고릅니다.
2. **▶ 실행** 버튼 또는 `Ctrl+Enter`(맥은 `Cmd+Enter`)를 누릅니다.
3. 콘솔에 실행한 사람의 이름·색상·시각, 출력, 소요 시간이 표시됩니다.
4. **■ 중지**는 실행 중인 코드를 즉시 강제 종료하고, **콘솔 지우기**는 모든 참여자 화면에서 기록을 지웁니다.
5. 편집기와 콘솔 사이 경계를 끌어 높이를 조절합니다. (방향키로도 조절, 높이는 브라우저에 저장됨)

누군가 실행 중이면 모든 화면에 "○○님이 실행 중..."이 표시되고, 그동안 다른 참여자의 실행 버튼은 비활성화됩니다.

### 지원 언어

| 언어 | 실행 방식 |
|---|---|
| JavaScript | Web Worker (최상위 `await` 사용 가능) |
| Python | [Pyodide](https://pyodide.org) (Web Worker 안에서 실행) |

HTML, CSS, TypeScript 등 그 밖의 언어를 선택하면 실행 버튼이 비활성화되고 이유가 표시됩니다.

### 확인용 예시

JavaScript
```js
console.log("hello")
console.log({ name: "철수", scores: [90, 80] })
undefinedFn()        // 오류 메시지와 줄 번호가 빨간색으로 표시됨
```
```js
while (true) {}      // 5초 뒤 "시간 초과로 중지됨" (또는 중지 버튼)
```

Python
```python
print("hello")
for i in range(3):
    print("반복", i)
print(1 / 0)         # Traceback이 표시됨
```

### 제한 사항

- **시간 제한 5초**: 넘으면 실행 Worker를 강제 종료합니다. (Python 준비 시간은 제한에 포함되지 않음)
- **출력 제한**: 한 번 실행에 1000줄까지만 저장하고, 방 전체 기록은 최근 500줄만 유지합니다. 한 줄은 5000자까지 저장합니다.
- **Python**: 처음 실행할 때 Pyodide(수십 MB)를 jsDelivr CDN에서 내려받으므로 인터넷 연결과 시간이 필요합니다. 한 번 불러온 뒤에는 재사용하며, 시간 초과·중지로 종료했다면 다음 실행 때 다시 불러옵니다. `input()`은 지원하지 않습니다. 실행마다 새 변수 공간에서 시작합니다.
- **한 번에 한 명만 실행**: 동시에 두 사람이 거의 같은 순간 눌러 둘 다 실행되면 출력이 섞일 수 있습니다.
- **중지·시간 제한은 실행한 사람의 브라우저에서만** 동작합니다. 실행자가 접속을 끊으면 실행이 중단됩니다.
- **다른 참여자가 편집한 코드가 실행될 수 있습니다.** 실행 전에 코드를 확인하세요. Worker는 화면(DOM)·쿠키·localStorage에는 접근할 수 없지만 네트워크 요청(`fetch`)은 보낼 수 있습니다.
- JavaScript의 `setInterval`은 `clearInterval`로 끝내지 않으면 진행 중으로 간주되어 5초 뒤 시간 초과로 중지됩니다.
- 콘솔 기록도 코드·언어와 같은 문서에 있어서 아래 "방 내용 저장"에 따라 서버에 함께 저장됩니다.
- 브라우저 탭이 백그라운드이면 타이머가 늦게 동작해 시간 제한이 몇 초 늦게 적용될 수 있습니다.

## 방 내용 저장

서버는 방의 내용을 SQLite 파일에 저장하므로, 서버를 껐다 켜도 같은 방 주소로 들어가면 이전 내용이 남아 있습니다.

- **저장되는 것**: 코드, 선택한 언어, 콘솔 출력 기록(같은 Yjs 문서에 들어 있어 함께 저장됩니다). 접속자 목록, 커서 위치는 임시 정보라서 저장되지 않습니다.
- **저장 파일 위치**: `server/rooms.sqlite` (실행 위치와 관계없이 항상 이 경로). `.gitignore`에 포함되어 있어 커밋되지 않습니다.
- **저장 시점**: 편집 후 약 2초 안에 저장됩니다. `Ctrl+C` 같은 정상 종료 신호에서는 저장되지 않은 내용을 저장하고 종료합니다. 프로세스를 강제 종료(`kill -9`)하면 마지막 몇 초의 편집이 사라질 수 있습니다.

### 저장 내용 초기화 (삭제)

서버를 종료한 뒤 저장 파일을 지우면 모든 방이 초기화됩니다.

```bash
# 서버를 먼저 종료한 다음 실행
rm server/rooms.sqlite
```

`-wal`, `-shm` 파일이 함께 생겼다면 같이 지웁니다: `rm server/rooms.sqlite*`

특정 방만 지우려면 서버를 종료한 뒤 SQLite로 해당 방(문서 이름 = 방 ID)의 행을 삭제합니다.

```bash
sqlite3 server/rooms.sqlite "SELECT name FROM documents;"             # 저장된 방 목록
sqlite3 server/rooms.sqlite "DELETE FROM documents WHERE name='방ID';"
```
